
## California pages, source registry and link hygiene (added 2026-10-02)

- **Shared builder, hand-written prose.** California city and category pages come from `scripts/build_ca_pages.py` in the same layout as the Ontario and BC pages (hero badge, rebate cards, local sections, installers, claim steps, visible FAQ with schema). The prose for each page is hand-written in `data/ca/pages/<city>/<category>.json` (and `index.json` for the city hub); never a fill-in template (see the `hpr-category-page-localization` and `hpr-no-doorway-pages` skills). The builder refuses a page under 750 words, with fewer than 4 FAQ items or 3 outside references, with more than one em dash, or containing "waitlist", "unclear" or "fully subscribed" (PowerScore reads those as a status). A page without a JSON file is not built; its URL redirects to the city hub. Cities that share one utility and offer identical amounts (Rancho Cordova and Folsom share SMUD with Sacramento) get a hub only. Run `python3 scripts/check_duplicate_content.py --near-duplicate-threshold 0.90` before committing. Add `git add -f data/ca` (data/ is gitignored).
- **Research first.** Read each program page in the browser pane (many utility sites block simple fetchers), put every amount in `data/verified-facts/*.json` with `status`, `verified_on` and `source_url`, then write the page. Re-read the page when you cite it; figures change (SMUD, LADWP and BWP all had stale numbers here).
- **Source registry for the monthly check.** `python3 scripts/build_source_registry.py` writes `data/rebate-sources.json` (every fact source, every page reference, plus extra program pages). Re-run it after adding facts or pages and `git add -f data/rebate-sources.json`. The `monthly-rebate-check` scheduled task (Step 1B) re-opens each entry.
- **Link hygiene after any generator run:** `python3 scripts/fix_redirected_links.py`, `python3 scripts/follow_official_sources.py` (official program sources are normal links, not nofollow), then `python3 scripts/check_internal_links.py` (fails on missing pages, links to redirected URLs, and pages shadowed by a redirect), then `python3 scripts/generate_sitemap.py`.
- **Hub pipeline order for California changes:** build_ca_pages, build_powerscore, build_powerscore_page, build_hub_tops, build_hub_showcase, build_hub_tidy, apply_canonical_nav_footer, check_hub_layout, build_home_powerscore, build_home_feed, then the link steps above. Old generators `build_ca_la.py`, `build_ca_sf.py`, `build_ca_sj.py` and `build_ca_sacramento.py` skip any city that has a folder in `data/ca/pages`.
