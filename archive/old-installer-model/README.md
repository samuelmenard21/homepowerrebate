# Retired installer model (archived 2026-10-11)

These documents pitch the old model: one paid "founding partner" installer per city at $300/month, with leads routed only to them. That model is retired. Do not send any of them to installers.

Current model: we list the top-rated installers in each city, ranked by Google reviews. Listing is free for now, and we never promise it will always be free. We only ask listed installers to show the top-rated badge. See /WHAT_TO_SEND_INSTALLERS.md.
