My Ontario Rebate Got Rejected. What Now?

A rejection usually means a fixable paperwork issue, not a dead end. Here's how to get back on track.

You Can Usually Fix This

A rejected rebate application feels final, but most of the time it's a specific, fixable issue — not a permanent no. Here's what commonly goes wrong with Ontario heat pump rebate applications, and how to resubmit successfully.

Common Rejection Causes

1. Non-participating contractor

Ontario rebate programs generally require your installer to be registered with the program. If your contractor isn't enrolled, the rebate can be denied even if the installation itself is fine. Ask directly: "Are you registered for this rebate program?" before signing anything.

2. Missing pre-inspection or pre-approval step

Some programs require an energy assessment or pre-approval step before work begins. If installation started first, the application can be rejected on that basis alone. For future projects, confirm the required order of operations before signing a contractor agreement.

3. Income documentation issues

If you're applying to an income-qualified tier for a bigger rebate, incomplete or mismatched income documentation is a common rejection reason. Double-check that your submitted documents match the names and addresses on your application exactly.

4. Program-specific paperwork gaps

Ontario has run several distinct programs over time, including the Home Renovation Savings Program — each with its own specific documentation requirements. If you're unsure which program you applied under, check your application confirmation email for the program name, then confirm the exact required documents for that specific program before resubmitting.

How to Resubmit

  1. Call or email the program directly and ask for the specific rejection reason in writing.
  2. Fix that specific issue — contractor enrollment, missing pre-approval, or documentation.
  3. Resubmit referencing your original application number.
