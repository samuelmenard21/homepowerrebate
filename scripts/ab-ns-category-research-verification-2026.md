## 2. New/Changed Finding: Edmonton Solar Rebate Program status

The Calgary page's copy ("ENMAX offers utility-specific incentives worth roughly $0–$2,000... Edmonton has its own 'Solar Rebate Program'" — referenced in the original brief) needs a status correction if that program is currently referenced anywhere as open:

**The City of Edmonton's Solar Rebate Program and Home Energy Retrofit Accelerator (HERA/"Change Homes for Climate") are both fully subscribed and NOT accepting new residential applications as of 2026.** The only currently-open piece is a narrower **multi-family solar program** ($1.2M allocated, $0.50/watt up to $4,000/dwelling, 4+ unit buildings only, reopened March 17, 2025, first-come-first-served) — not relevant to a single-family-home city page. For single-family homes, the closest live incentive named is the **Alberta Solar Club** net-export rate ($0.16/kWh), which is a buy-back rate, not a rebate.

- Sources: [epcor.com residential rebates page reference](https://www.epcor.com/ca/en/ab/edmonton/account/rates/alberta-government-rebates.html), [stellarupgrades.ca Alberta Solar Rebates 2026](https://stellarupgrades.ca/blog/alberta-solar-incentives-rebates-2026) — 2 consistent sources, both stating "fully subscribed... not accepting new applications"
- **Confidence: Medium-High (2 consistent sources, but no direct fetch of edmonton.ca's own program page succeeded this pass)**
- **Recommended action:** If Edmonton's own subpage (`ca/ab/edmonton/`, not read this pass) currently presents the Solar Rebate Program as open/available, it should be flagged for a direct correction — this is a real drift finding, closer in kind to BC's CleanBC ESP restructuring than a minor nuance. **Do not edit without reading `ca/ab/edmonton/index.html` and `ca/ab/edmonton/solar/` directly first**, since this pass did not read those files.
